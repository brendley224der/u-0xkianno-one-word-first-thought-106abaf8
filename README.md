A deterministic first-thought word picker for make.fun's "One Word, First Thought" bounty. It scores a small lexicon of candidate words on surprise, vividness, wit and specificity — the qualities the judge weighs — and writes the single winning word to `/output/entry.txt`. Pure Python standard library, no randomness, no network: every run writes the same word.

## Run it

```sh
python3 main.py
```
